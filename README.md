# Eco Store

## Resumen

Catálogo estático de productos ecológicos. El ejercicio organiza artículos por categorías y practica tarjetas de producto y estilos con Sass.

## Cómo verlo

Abre [index.html](index.html) para ver el catálogo con su hoja de estilos compilada.

[scss/main.scss](scss/main.scss) contiene los estilos fuente y [css/main.css](css/main.css) es la hoja que carga la página.

## English summary

A static catalog for eco-friendly products. The exercise covers product categories, product cards, and styling with Sass.
